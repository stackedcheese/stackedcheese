## Mathematical foundations

- Pool-Adjacent-Violators monotone projection, split conformalized quantile regression and Power/Shin probability normalization.
- Anytime-valid sequential e-processes, Ville bounds and e-BH false discovery control.
- Multirate signal alignment with subject-grouped evaluation and sparse symbolic recovery on synthetic dynamics.
- Three-clock point-in-time checks and SHA-256/Merkle evidence binding. See the [live workbench](https://stackedcheese.com/research) for the browser verification surfaces.
